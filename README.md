## Objective

To establish a reproducible computational biology workflow following FAIR data principles, version control and software provenance.

## Computational Environment

- Python 3.11.18
- NumPy 2.4.6
- pandas 3.1.0
- Matplotlib 3.11.2
- JupyterLab 4.6.4
- Conda environment: compbio-p0

## Environment Setup

The computational environment will be documented in environment.yml and can be reconstructed using:

`conda env create -f environment.yml`

`conda activate compbio-p0`

## Reproducibility

The environment will be tested independently on two Windows laptops:

- HP Omen: Primary research system
- Dell: Independent verification system

## FAIR Principles

- **Findable:** Identifiable datasets and documented accessions.
- **Accessible:** Clearly defined data access procedures.
- **Interoperable:** Standard data formats and controlled vocabularies.
- **Reusable:** Documented methods, provenance and licensing.
